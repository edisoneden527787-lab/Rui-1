# Rui Photo Studio

Android native Kotlin + Jetpack Compose first-stage build.
Implemented: Android Photo Picker image import, image preview, real CPU pixel adjustments (exposure, contrast, saturation, temperature), before/original toggle, reset, JPEG export to Pictures/Rui Photo Studio.
Not yet implemented: HSL, curves, local masks, AI segmentation, layers/blend modes, AI auto enhance, automotive mode, GPU/tiled rendering, durable project recovery, manual numeric entry. This is an MVP build and not the complete product specification.
Target SDK 36, min SDK 29, JDK 17.
